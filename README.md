# Cafe Sales Cleaning and Analysis
This project cleans and analyzes café sales data to uncover meaningful business insights, which are then visualized in an interactive Power BI dashboard.

## 📊 Overview
The dashboard shows insights regarding the sales of a cafe, including information such as: 
1. Top Selling Items
2. Months Where Sales are the Highest
3. Most Popular Payment Methods
4. Weekend vs Weekday Purchasing Data

## 🛠️ Tools & Technologies
- Power BI
- MySQL / SQL

## 🔍 Data Cleaning & Transformation
1. Removed Duplicate Data
2. Standardized Formats
3. Removed/Filled out Null/Blank Data
4. Removed Unecessary Rows/Columns

## 📈 Key Features
- KPI cards  
- Rolling totals  
- Weekend vs Weekday analysis  
- Trend charts  
- Treemap / bar chart visuals
- DAX measurements
- Connected MySQL databases to Power BI
